# 🏗️ Civil Engineering BIM Extractor

An AI-powered Streamlit web application that allows Civil Engineers to upload modern PDF designs or scanned paper blueprints. It uses Google's Gemini Multimodal AI to extract BIM data, dimensions (length/width), materials, and structural elements.

## Disclaimer
**AI is not 100% accurate.** This tool is designed to assist engineers by doing the heavy lifting of data entry, but all extracted measurements and structural data MUST be verified by a qualified human engineer before use in actual construction or calculations.

## How to Run Locally

1. Install the dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the Streamlit app:
   ```bash
   streamlit run app.py
   ```
3. Open the local URL provided in your terminal and enter your Gemini API Key to start analyzing designs!
